# suwa-app

Aplicación móvil (React Native) — se scaffoldeará en la fase de frontend.

## Cómo inicializar (cuando lleguemos a esa fase)

Con Expo (recomendado para ir más rápido):

```bash
cd app
npx create-expo-app . --template blank
npm install axios socket.io-client react-native-chart-kit expo-notifications
```

## Pantallas planeadas

- Login / Registro
- Dashboard: humedad de suelo, temperatura, humedad ambiente en tiempo real
- Historial de riegos (gráfica)
- Configuración de umbrales de riego automático
- Botón de riego manual
- Centro de alertas / notificaciones
